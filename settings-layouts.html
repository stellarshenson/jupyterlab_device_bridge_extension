Serial settings dialog - layout options

Five proposals for the Devices panel settings dialog. The current dialog is first for comparison. Baud rate is one control in every proposal: an editable field that lists the standard rates and accepts a typed value, marking it Custom when the value is not standard. Toggle the theme at the top.

What I suggest

  • Layout A or E. A if the dialog should stay quiet; E if the common rates deserve one click. Both use the same table and the same single baud control.
  • One control per row. The select plus text field pair is the only place the current dialog breaks the column; an editable field with a rate list removes it and marks a typed value Custom.
  • Shaded rows, not borders. Alternating bands carry the eye across from label to value; the dialog keeps the lab's flat surfaces and adds no lines.
  • Columns fixed at 42/58. Labels end at one line, controls start at one line, every control is the same width and height.
  • Summary in the footer. 115200 8N1 restates what the table says, which catches a misread before Save.
  • Keep the button order and emphasis. Save stays the only accent; Delete config stays the warning colour; Cancel and Save as... stay secondary.
  • Validation. Accept 1 to 4000000 in the field; an out-of-range or empty value shows the hint and disables Save, instead of failing after the request.
